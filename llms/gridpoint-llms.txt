# GridPoint

> GridPoint (Reston, Virginia; founded 2003) builds energy management and
> sustainability systems for commercial buildings — edge controllers, submeters,
> thermostats and lighting panels paired with the cloud-based GridPoint Energy
> Manager analytics platform. It serves multi-site retail, convenience,
> restaurant, automotive and public-sector portfolios.

## Important: GridPoint publishes no public API

As of 2026-08-22 GridPoint has no developer portal, no API reference, no
OpenAPI/AsyncAPI/GraphQL contract, no SDK, no Postman collection, no MCP server
and no A2A agent card. developer.gridpoint.com, docs.gridpoint.com,
api.gridpoint.com and apidocs.gridpoint.com do not resolve in DNS. An API
demonstrably exists behind the customer application, and GridPoint's own
authorization server advertises the client_credentials grant plus partner and
system roles — but its contract and reference are customer/partner-gated.
Do not infer endpoints, parameters or payloads for GridPoint; none are published.

## Identity (the only machine-readable API surface GridPoint publishes)

- [OpenID Connect discovery](https://hydra.gridpoint.com/.well-known/openid-configuration): Issuer https://hydra.gridpoint.com:443/, ORY Hydra. Grants: authorization_code, implicit, client_credentials, refresh_token. Anonymous, 200

- Also served, byte-identical, from https://identity.gridpoint.com/.well-known/openid-configuration and https://ems.gridpoint.com/.well-known/openid-configuration
